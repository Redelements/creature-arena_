# Open items

Placeholders, what's built and what isn't, planned work and known issues.
Priorities are in the Game Plan doc, "Game modes". Refreshed 2026-10-27 (unattended QA sweep,
`docs/autonomy-log.md`).

- **Art, fighters:** all ten fighters, Cairn and the training dummy are generated rigs
  (`tools/gen_<id>.py`, drawn through `tools/splat3d.py`, `shade2d.py` or their own
  rasterisers). The whole roster is at **2x density** (route A, Oct 2026, PRs #237-#248: 192 or
  256 px frames, packed sheets `tools/pack_sheets.py` keep a 4v4 at about 160 MB of texture).
  The training dummy is still at 1x. The rigged fighters gained real detail at 2x; the painted
  ones (Barkley, Gillbert, Craglash) only crisper edges: real detail there means redrawn shapes,
  which is art work. PixelLab regeneration was tried and rejected (smeared, inconsistent frames;
  `docs/pixellab-spec.md`, branch `crease-2x-spike` kept unmerged). An artist is making new
  characters and movesets; the delivery format is still to be agreed; spec for drop-in art:
  `docs/SPRITES.md`.
- **Art, arenas:** all six maps are tiled from bought Szadi packs with raised walls, sunken
  water and scatter (#234) and hand-dressed (Twin Keeps pilot, then #254-#258 for the other
  five; dressing scenes in `assets/arenas/<id>_dressing.tscn`, galleries `docs/maps/`). Only
  the effects sheet and a few overlays are still programmer art (`tools/gen_sprites.py`).
  Rulings open for Kevin: margin / hoarding props (every map named a candidate in its PR),
  a second buildings pack on one map (Greenhouse windmill sacks, Quarry tools). Szadi's written
  OK for the cuts in a public repository is still pending (`LICENSES.md`).
- **Audio: TODO, all placeholder.** Everything in `assets/audio/` is generated by
  `tools/gen_audio.py`; checklist in `docs/AUDIO.md` and the "Replace placeholder audio" GitHub
  issue (#3). Proximity voice chat is built (#218).
- **Online:** direct 1v1 over UDP and a dedicated relay/referee server are built, with
  online 2v2/3v3 through the server (any team rules: deathmatch, Sinkhole, Crater, Caravan,
  Capture the Flag), online 4v4 Capture the Flag, 3v3 tag Duels, spectators, saved online
  replays, arenas online (the host's or the room's, random for Quick match), an input delay
  setting, ranked 1v1 with Glicko ratings, Daily scores verified on the server, player secrets,
  proximity voice chat. Hardened in Oct 2026 (#212, #213, #215). Not yet: a Steam transport
  (behind `NetLink`), reconnecting after a drop. The server runs the protocol of whatever main
  was last deployed with `tools/server/update.sh` (NET_VERSION 58 at this writing).
- **Android:** a debug APK builds in CI (arm64, export preset "Android") and runs on an AYN
  Odin 3 with the same match fingerprint as PC. Built since: touch fight controls with a
  target lock (#201, `src/input/touch_pad.gd`, `touch_target.gd`), menus that fit phones and
  handhelds (#200, `tests/test_ui_fit.gd`), Vulkan on Android with CPU thinking between ticks
  and vsync pacing so the Odin holds 120 Hz (#226; the default fight cap stays 60), a device
  perf runner (`tools/odin_perf.py`). Not yet: an app icon (the preset's `launcher_icons` are
  empty), release signing, a Play Store listing, a shader warm-up for the first-run hitch.
  Open for Kevin: the touch targeting spec (cancel zone, default priority, objective button).
  iPhone: not started (needs a Mac build in CI and a paid Apple Developer account).
