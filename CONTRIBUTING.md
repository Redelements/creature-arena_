# Contributing

Ready 4 Rambles is a solo commercial project. **Outside contributions are not accepted**: pull
requests from anyone other than the owner (Redelements) are closed unread, and issues are read
as bug reports and suggestions only.

Why: the game is sold, and every line of code and every asset in it must be owned outright or
licensed in writing (see `LICENSE` and `LICENSES.md`). Merging a contribution without a signed
assignment would muddy that, so none are merged.

If you found a bug, open an issue with the build you played (the download's name carries the
commit id), the mode, and what happened; a `--bug-report` zip (Settings > Save a bug report) says the rest. If you want to
discuss a licence for any part of the game, open an issue and say so; the owner answers there.
